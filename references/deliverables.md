# 文件交付合同

## 输出目录与文件

获得 E1+E2（指标另需 E3）并通过内容校验后，在用户指定目录或当前工作区 `resume-deliverables/` 中创建以下脱敏文件：

1. `匿名简历-通用版.md`：标准 Markdown 简历，适用于一般编辑器。
2. `匿名简历-CodeCV.md`：可粘贴到 CodeCV 的 Markdown 载荷。
3. `项目简介卡.md`：逐项目说明项目是什么、服务场景、核心能力、技术要点和验证状态。
4. `简历校验结果.json`：仅含文件名、字节数、摘要和通过/失败状态；不得含 URL、路径、项目名、代码片段或个人信息。

只拥有 E2 而没有 E1 时，最多写入 `项目简介卡.md` 与匿名缺口说明；不得生成包含个人成果的两份简历文件。

## 项目简介卡

每个项目包含五个匿名字段，每项不超过 120 字：

- 项目定位：项目类型和服务对象。
- 服务场景：解决的泛化问题或业务流程。
- 核心能力：从源码可观察到的模块能力。
- 技术要点：与场景相关的机制，不堆砌技术名词。
- 验证状态：仅说明“源码结构已核验/待确认个人贡献/待确认指标”等匿名状态。

项目简介卡不得包含个人动作、成果、数字指标、项目名、组织名、URL、路径、类名、文件名、日期或来源元数据。

## 交付完成定义

- 两份简历与项目简介卡均非空，且两份简历的成果条目数量与标题集合一致。
- 每个项目在两份简历中均含项目简介；简介用中性语言说明项目是什么，不替代成果条目。
- `简历校验结果.json` 由 `validate_deliverables.py` 生成，并显示通过。
- 最终回复先说明匿名项目定位，再给出所有文件的绝对路径和校验结果。
