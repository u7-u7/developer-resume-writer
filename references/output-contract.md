# 项目经历输出格式

## 默认 Markdown

```markdown
## <项目名称>

**项目简介**：<用 80–150 字说明项目定位、服务场景、核心能力和技术机制>

**技术栈**：`技术 A`、`技术 B`、`技术 C`

### 项目产出

- **小标题**｜具体动作 + 技术方案 + 可确认结果
```

项目简介先回答“项目是什么”，项目产出再回答“做出了什么”。每条产出单独成行且不超过 200 字。

## CodeCV（可选）

用户明确要求 CodeCV 时，可将同一段内容放进 `项目经历` 区块，并使用模板 https://www.codecvcv.com/jianlimoban/15simple_versatile。建议主色 `#2F5CC4`、字号 `17`、行距 `15`、上下边距 `22`。
