# CodeCV 输出合同

## 允许的固定顺序

1. `::: headStart` 头部区块
2. `教育经历`
3. `实习经历/工作经历`
4. `项目经历`
5. `专业技能`
6. `奖项/校园经历`（无安全内容时省略）
7. `待确认`（最多五条，完全匿名）
8. `CodeCV 设置`

## 最小骨架

```
::: headStart
::: start
## **<泛化目标岗位>**
<不含身份信息的求职概述>
:::
::: end
::: headEnd

## 实习经历/工作经历
::: start
### **某业务平台** - <泛化岗位>
**技术栈**：`技术名称`
:::
**某年—某年**
::: end
- **小标题**｜动作 + 技术方案 + 已证实结果

## 项目经历
::: start
### **某领域服务平台** - <泛化岗位>
**项目简介**：面向某类用户的某领域应用服务，用于处理核心业务流程；通过模块化服务、数据处理和边界控制支撑关键能力。
**技术栈**：`技术名称`
:::
**某年—某年**
::: end
- **小标题**｜动作 + 技术方案 + 已证实结果

## CodeCV 设置
- 模板：https://www.codecvcv.com/jianlimoban/15simple_versatile
- 主色：#2F5CC4；字号：17；行距：15；上下边距：22
```

## 聊天交付

在聊天中返回时，用一个外层 `markdown` 代码围栏包裹上述内容，以便用户完整复制；粘贴到 CodeCV 前仅复制围栏内内容。围栏不是简历内容，不要交给校验器。

## 通用 Markdown 版

通用版必须包含 `# 匿名研发简历`、`## 项目经历`、泛化项目标题、`**项目简介**：` 和与 CodeCV 版等价的成果条目。不要使用 CodeCV 区块语法、头像、链接或来源信息。

## 禁止项

不得使用图片、链接（模板链接除外）、头像、`icon:`、表格、HTML、CSS、引用、代码围栏、原始附件文字和不在固定顺序中的章节。除“待确认”和“CodeCV 设置”外，禁止在简历后附加说明。
